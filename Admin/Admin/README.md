# ⚡ Electricity Bill Management System
A web-based application to simplify and automate the process of generating and managing electricity bills for renters. Built to replace my manual, paper-based billing system that took ~5 minutes per renter per month.

# 🧠 Why I Built This
As someone renting out multiple units, I found manually calculating, writing, and sending electricity bills every month to be inefficient and error-prone. This system was developed to save time, improve accuracy, and scale with more renters.
 
## 🚀 Features
-> 📩 Bill Generation: Add new bills per user with amount and status (Pending, Paid)

-> 📊 User Dashboard: Renters can view their current and past bills

-> 🛠 Admin Panel: Admin can view all users, manage bills, and change statuses

-> 🧾 Complaints System: Users can submit complaints (e.g. incorrect bill), and admin can resolve them

-> 🔐 Role-based Access: Separate routes for users and admin, with JWT authentication

# 🛠 Tech Stack
-> Frontend: React.js

-> Backend: Node.js, Express.js

-> Database: MongoDB

-> Authentication: JWT (JSON Web Token)

-> State Management: React Context API

# 📈 Real Impact
Reduced billing time from ~5 minutes per user to a few seconds

-> Currently managing 10 renters, with plans to scale

-> Improved transparency and reduced user complaints


## 💡 Future Improvements
-> SMS/email notifications for generated bills

-> Graphical insights and monthly usage stats
